# Saoqiang 微信素材 0.11.5 对照清单测试版

0.11.17 起显示名为「小扒手」，入口在微信「插件」列表里。面板顶部有总开关，默认关闭；
关闭时 dylib 仍然注入，但所有抓取钩子直接转回原实现，不产生额外开销。

新增通用 JSON 对照清单导入：在「工具 → 导入 / 移除当前主题对照清单」选择清单，然后重新导出。清单必须与当前 themeID 一致，包含每项精确 key、bytes、sha256。新引擎逐项主动调用原文件接口，不再只等页面缓存；对照条目绕过旧捕获缓存。错误长度或哈希拒绝保存，缺失与不符分别报告；对照不符时会在manifest.json的referenceObserved记录实际长度、SHA-256、格式和读取来源，原数据仍不写入素材文件。对照覆盖不等于封包完整性，没有导入清单的主题仍按已有清单导出。

参考JSON：`{"themeID":"当前主题ID","items":[{"key":"exact.svg","bytes":123,"sha256":"64位十六进制SHA-256"}]}`。也可导入含相同字段的旧导出 manifest.json；不接受重复键、绝对路径、穿越、dat/配色/回执项或超过限制的清单。对照文件只包含名称/长度/哈希，不含原图数据；不会把对照文件拷贝成导出素材。

注入后完全重启微信、应用同一套主题，导入配套JSON再点一键导出。验收重点为 referenceMatched / referenceCount、referenceMissing、referenceMismatch 和 referenceComplete。referenceComplete 只表示参考清单逐项字节一致，complete 仍保持未知。

本次补充主题盒子3.0.8新引擎适配和当前主题配色原文件导出，保留0.11跨页累计、单图原名保存、普通气泡/红包原名和五标签界面。未恢复ZIP打包或面板美化。

**微信和主题盒子均不按版本号/UUID锁定，运行时检查真实可用接口。**接口不同会分别识别旧ThemeBoxImageLoader与新ThemeBoxAssets。版本不限不等于所有版本全部实测；未知ABI拒绝调用并给诊断。

当前主题目录中的 `weui_color_new.xml` 与 `color.css` 会按文件原名保存真实文件字节，不经过图片渲染或扩展名改写。缺少/链接不安全时不从别的主题、receipt或聊天目录借用。启用0.11.2后应用主题盒子目标主题，再执行“当前主题素材一键导出”，在导出目录查看配色文件。

对3.0.8的新引擎，`ThemeBoxAssets.themeFiles` 是当前散装主题目录映射；也包含当时已加载索引与活动覆盖。封包 `themebox.dat` 原件可另存，但其文件名索引没有经验证的可枚举接口：报告会明确标“封包原件已保存，内部图标尚未全部展开”，不会把封包保存误报成全部图标已拆出。完整展开封包仍需有效、每套主题变化的资源名称清单；不猜名称/偏移，不修改其格式。

## 验证边界

3.0.8样本最低部署条件iOS15/arm64e并带Roothide注入目录；新引擎通过配置renderingEngine开关。已编写模拟新旧引擎选择、XML/CSS逐字节导出、源变化和外部符号链接拒绝回归。配色和散装资源按当前ThemeBoxMgr.currentThemePath读取。封包完整枚举未知，须用户主题目录逐项检查；模拟测试通过不代表任意主题的themebox.dat已解包完成。

安装时在TrollFools移除旧版此插件、注入新dylib、完全退出微信重开；不卸载微信、不同时注入两版。用户deb、IPA、主题封包/截图/视频不会上传；云端仅编译自有插件源码和合成测试。
